PIXEL ARCADE

Avvio della dashboard

Questa pagina contiene solo le istruzioni. La dashboard vera gira sulla console, servita da Pixel Arcade.

  1. 1
    Prepara la build (una volta, dal PC): cd dashboard/frontend && npm ci && npm run build
  2. 2
    Avvia sulla console: bash run_dashboard.sh. Chrome si apre a schermo intero, senza barre né schede.
  3. 3
    Senza Chrome automatico: bash run_dashboard.sh --no-browser, poi apri http://127.0.0.1:8765 sulla console.
  4. 4
    Per fermare: chiudi la finestra della dashboard oppure premi Ctrl+C nel terminale del servizio. In entrambi i casi si fermano sia il servizio sia il Chrome aperto da Pixel Arcade.

Dettagli su build, database e sviluppo in dashboard/README.md.
